
# SOMA DE LISTA


```python

numeros = [1, 2, 3, 4, 5] #lista de numeros
soma = 0 # vai começar aqui
i = 0 # i vai ser a posição da lista
while i < len(numeros):# vai ver se i e menor que a quantidade de items na lista e criar um loop
  soma += numeros[i]# soma vai aderir soma + um indice da lista
  i += 1 # vai somar mais 1 na variavel i

  print(soma) # vai printar na tela


```

# NUMERO PRIMO


```python

o = int(input("qual num quer saber se e primo ou nao ")) # Solicita ao usuário um número e o converte para inteiro

def eh_primo(n): # Define uma função chamada 'eh_primo' que recebe um número 'n'
    if n < 2: # Verifica se o número é menor que 2
        return False # Se for menor que 2, não é primo
    if n == 2: # Verifica se o número é igual a 2
        return True # Se for 2, é primo
    if n % 2 == 0: # Verifica se o número é par (e maior que 2, pois o caso 2 já foi tratado)
        return False # Se for par e maior que 2, não é primo
    # Verifica apenas divisores ímpares até a raiz quadrada de n para otimização
    i = 3 # Começa a verificar divisores a partir do 3
    while i * i <= n: # Loop que continua enquanto i ao quadrado for menor ou igual a n (otimização de raiz quadrada)
        if n % i == 0: # Verifica se n é divisível por i
            return False # Se for divisível, não é primo
        i += 2 # Incrementa i em 2 para verificar apenas números ímpares
    return True # Se nenhum divisor for encontrado, o número é primo

print(eh_primo(o)) # Chama a função eh_primo com o número fornecido pelo usuário e imprime o resultado

```
